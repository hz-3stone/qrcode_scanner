# QR ClipDecode

クリップボードにコピーしたQRコード画像を読み取り、中身（URLなど）を取り出すWebツールです。
取り出した文字列は、自動でクリップボードにコピーされます。

## できること

- **クリップボードから読み取る**: 「クリップボードから変換」ボタンを押すと、クリップボードにある画像を解析します
- **ファイルから読み取る**: 画像をドラッグ＆ドロップするか、クリックしてファイルを選ぶと解析します
- **結果を自動でコピーする**: 解析に成功すると、結果の文字列をクリップボードに書き込みます。コピーボタンで再コピーもできます

解析はすべてブラウザの中で行います。画像はサーバーへ送信しません。

## 動作条件

- localhost か HTTPS のページで開いてください。クリップボードAPIは、この2つでだけ使えます
- 「クリップボードから変換」を初めて使うとき、ブラウザが読み取りの許可を求めます。「許可」を選んでください
- クリップボードの画像読み取り（`navigator.clipboard.read`）に対応していないブラウザでは、ドラッグ＆ドロップかファイル選択を使ってください

## 使い方（開発）

Node.js をインストールしてから、次のコマンドを実行します。

```bash
npm install      # 依存パッケージを入れる
npm run dev      # 開発サーバーを起動する（http://localhost:5173）
npm run build    # dist/ に本番用ファイルを作る
npm run preview  # ビルド結果をローカルで確認する
```

## 使っている技術

- [Vue 3](https://vuejs.org/)（`<script setup>`）
- [Vite](https://vite.dev/)
- [jsQR](https://github.com/cozmo/jsQR)（QRコードの解析）
